# 🏠 California Housing Price Predictor

แอปพลิเคชัน Streamlit สำหรับทำนายราคาบ้านในแคลิฟอร์เนียโดยใช้ Machine Learning (Random Forest)

## 🚀 วิธีการ Deploy

1. Clone repository นี้
2. ติดตั้ง dependencies: `pip install -r requirements.txt`
3. รันแอป: `streamlit run app.py`

## 📁 โครงสร้างไฟล์
- `app.py`: โค้ดหลักของ Streamlit
- `requirements.txt`: รายการ Python packages
- `model_files/`: โฟลเดอร์เก็บไฟล์โมเดล (.pkl)
